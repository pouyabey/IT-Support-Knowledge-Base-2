# IT-Support-Knowledge-Base-2

This repository documents real-world IT troubleshooting issues I encounter and resolve during my work.

## Troubleshooting Workflow

**Clarify the Issue → Determine the Scope → Check the Basics → Isolate the Cause → Apply the Fix → Verify the Resolution → Document the Issue**

- **Clarify the Issue** — Understand the exact symptoms.
- **Determine the Scope** — Identify who or what is affected.
- **Check the Basics** — Rule out simple and common causes first.
- **Isolate the Cause** — Narrow the issue down to the most likely source.
- **Apply the Fix** — Use the least risky appropriate solution.
- **Verify the Resolution** — Confirm the issue is fully resolved.
- **Document the Issue** — Record the symptoms, cause, troubleshooting steps, and resolution.
