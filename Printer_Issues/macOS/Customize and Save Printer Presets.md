# macOS – Customize and Save Printer Presets

## Issue

A user reported that the Building A color printer no longer showed the detailed printing options that were previously available, such as:

- One-sided / two-sided printing
- Bypass Tray selection
- Paper type
- Stapling and finishing options
- Cover and other advanced printer settings

The goal was to restore access to these settings and provide an easy way for the user to save frequently used configurations as presets.

---

## Resolution

The advanced options are available through the macOS print dialog under:

File > Print
→ Printer Options
→ Printer Features

From there, the user can configure the required print settings and save them as a reusable preset.

---

## Example: One-Sided Printing from the Bypass Tray

1. Open the document and select:

   File > Print

2. Select the Building A color printer.

3. Scroll to:

   Printer Options > Printer Features

4. Configure the print job:

   Print Type: 1-Sided
   Paper Tray: Bypass Tray
   Paper Type: Plain Paper

5. Leave unnecessary options such as Staple, Fold, Covers, Carbon Copy,
   and Copy Security disabled unless they are specifically needed.

---

## Save the Settings as a Preset

After configuring the printer:

1. Return to the main Print window.
2. Open:

   Presets > Save Current Settings as Preset

3. Give the preset a descriptive name, for example:

   Building A - Bypass - One Sided

4. Make the preset available for the selected printer.
5. If prompted for a preset type, choose:

   Print Job Preset

The saved configuration can now be selected from the Presets menu for future print jobs.

---

## Notes

- Printer options may appear differently depending on the macOS version and installed printer driver.
- Some Konica Minolta drivers may display settings such as Layout / Finish or Paper Tray / Output Tray directly under Printer Options.
- Settings under Per Page Setting apply only to selected pages; use the main Print Type and Paper Tray controls when configuring the entire document.
- When using the Bypass Tray, make sure the paper loaded in the printer matches the selected paper size and type.
